# SDK preview: 1080p60 with SDL2

[Download the frozen preview](https://github.com/blackbearreloaded/ps5-opengl/releases/tag/sdk-0.1.0-perf20260908-g25-sdl2-sampled).

This fixed 1080p60 GL/SDL2 package has 204/204 sampled passes, focused
application/transfer checks and a bounded SDL window/context test. It is
experimental, not a full CTS rerun or Khronos certification.

The archive includes libraries, headers, consumer metadata, sources, examples,
licenses, SHA-256 checksums and exact-binary evidence. Use its included guide
for the original build identities and qualification.

For new integrations, prefer [SDK 0.2.0](release-g62.md).
See [SDK consumption](consumer-build.md) and [SDL2](../integration/SDL2/README.md).
The preview does not contain later GPU optimizations or the runtime reopen guard.
